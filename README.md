# About: 

The main goal of this Semestral project was to train an artificial neural network to detect sensor faults using time-series data. The training data is a set of temperature readings from different rooms in a smart home.

<img src="https://github.com/user-attachments/assets/74970b66-10fd-4771-a9e4-de2f1123858f" alt="Description" width="480" height="320"/>
</div>

In the end, the best results were achieved with an LSTM network that predicts the probability of different types of sensor faults given a time-series segment from all the sensors.
